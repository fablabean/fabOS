La API: se paga con créditos

Ya no chateas tú: tu programa le habla a la IA, y cada llamada se descuenta de tu saldo.

Compras créditosprepago, desde USD 5
Creas una llaveva en el .env
Tu programa llamauna vez o mil
El modelo respondetexto o JSON
Se descuentapor tokens usados
Claudeconsole.anthropic.com ↗Créditos prepago. Tope de gasto mensual.
Geminiaistudio.google.com ↗Nivel gratis con límites; luego facturación de Google Cloud.
OpenAIplatform.openai.com ↗Créditos prepago. Límites de uso por proyecto.
Licencia del chatValor fijo al mes. Para ti, en la pantalla.
Créditos de la APIPagas lo que uses. Para tus programas: con un modelo pequeño, mil correos cuestan centavos.

Cuida el saldo

La llave es dinero

En el .env, fuera de Git y fuera del chat. Si se escapa, bórrala y crea otra.

Pon un tope

Límite de gasto mensual en la consola. Un programa en bucle puede hacer miles de llamadas.

Mira el consumo

Cada respuesta trae sus tokens: entrada + salida. La consola muestra cuánto llevas.
Ver la llamada en código

Tu IA:

oficio.py · Claude
from dotenv import load_dotenv
import anthropic

load_dotenv()                      # lee ANTHROPIC_API_KEY del .env
cliente = anthropic.Anthropic()

def clasificar(texto):
    mensaje = cliente.messages.create(
        model="claude-haiku-5-5",
        max_tokens=50,
        system="Clasifica el correo en una sola palabra: urgente, informativo o spam.",
        messages=[{"role": "user", "content": texto}],
    )
    print("tokens:", mensaje.usage.input_tokens, "+", mensaje.usage.output_tokens)
    return mensaje.content[0].text

print(clasificar("Asunto: su factura vence hoy y se suspende el servicio"))
oficio.py · Gemini
from dotenv import load_dotenv
from google import genai
from google.genai import types

load_dotenv()                      # lee GEMINI_API_KEY del .env
cliente = genai.Client()

def clasificar(texto):
    respuesta = cliente.models.generate_content(
        model="gemini-flash-latest",
        config=types.GenerateContentConfig(
            system_instruction="Clasifica el correo en una sola palabra: urgente, informativo o spam."),
        contents=texto,
    )
    print("tokens:", respuesta.usage_metadata.total_token_count)
    return respuesta.text

print(clasificar("Asunto: su factura vence hoy y se suspende el servicio"))
oficio.py · GPT
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()                      # lee OPENAI_API_KEY del .env
cliente = OpenAI()

def clasificar(texto):
    respuesta = cliente.responses.create(
        model="gpt-5-mini",
        instructions="Clasifica el correo en una sola palabra: urgente, informativo o spam.",
        input=texto,
    )
    print("tokens:", respuesta.usage.input_tokens, "+", respuesta.usage.output_tokens)
    return respuesta.output_text

print(clasificar("Asunto: su factura vence hoy y se suspende el servicio"))

04

Construimos un agente

El agente que ordena una carpeta revuelta: lee cada archivo, decide a dónde va, lo mueve y te deja un informe. Lo pruebas con archivos de mentira.

Una carpeta revuelta8 archivos de prueba
El agente leey piensa con la API
Decide y mueveFACTURAS, ESTUDIO, PERSONAL
Deja un informecon el total de facturas
Tú revisasen el explorador
  • Herramientas: listar, leer, mover e informar. Nada más.
  • Por qué IA y no una regla: «doc1.txt» no dice qué es; hay que leerlo y entenderlo.
  • Límites: máximo 20 pasos; nunca borra; no sale de la carpeta.
  • El modelo solo pide: quien mueve los archivos es el código que tú aprobaste.

El guion, paso a paso

  1. Abre una carpeta vacía agente en VS Code, con tu .env (la llave). Pídele a Claude Code los archivos de prueba:
    Pedido para copiar en Claude Code
    Crea una carpeta «revuelto» con estos 8 archivos de texto de prueba,
cada uno con una sola línea:
doc1.txt           «Factura N.º 2231 · Energía · Total a pagar: $184.500 · Vence el 30 de noviembre»
scan_0034.txt      «Recibo de caja · Papelería El Lápiz · 3 cuadernos · $23.000»
whatsapp_0912.txt  «Factura electrónica FE-889 · Internet hogar · $95.000»
apuntes.txt        «Estadística: media, mediana y moda. Ejercicios 1 a 5 para el lunes.»
clase3.txt         «Clase 3: el ciclo de vida del producto y sus cuatro etapas.»
final_v3.txt       «Informe del proyecto final. Introducción: el problema que resolvemos…»
nota.txt           «Comprar: huevos, café y pan.»
importante.txt     «Cita médica el martes 2 de diciembre a las 7 a. m.»
    doc1.txtscan_0034.txtwhatsapp_0912.txtapuntes.txtclase3.txtfinal_v3.txtnota.txtimportante.txt
  2. Pídele el agente, y que te muestre el plan primero:
    Pedido para copiar en Claude Code
    Crea agente.py: un agente que use la API de Anthropic (modelo claude-haiku-5-5,
llave ANTHROPIC_API_KEY del .env) con tool use y estas cuatro herramientas:
- listar(): los archivos de la carpeta revuelto/
- leer(nombre): el contenido de un archivo
- mover(nombre, carpeta): lo mueve a revuelto/FACTURAS, ESTUDIO o PERSONAL
- informe(texto): escribe informe.md
Objetivo: dejar cada archivo en su carpeta y un informe con lo que hizo
y el total de las facturas.
Límites: máximo 20 pasos; nunca borra; no sale de revuelto/;
imprime cada paso y, al final, los tokens usados.
Primero muéstrame el plan. No escribas código hasta que lo apruebe.
  3. Lee el plan en voz alta con la sala: ¿están las cuatro herramientas?, ¿los límites?, ¿que nunca borre? Corrige lo que falte y apruébalo.
  4. Córrelo (python agente.py) con el explorador de VS Code abierto: se ve cómo los archivos se van moviendo.
    Lo que verás (ilustrativo)
    [1]  listar()                      → 8 archivos
[2]  leer("doc1.txt")
[3]  mover("doc1.txt", FACTURAS)
[4]  leer("scan_0034.txt")
[5]  mover("scan_0034.txt", FACTURAS)
[6]  leer("whatsapp_0912.txt")
[7]  mover("whatsapp_0912.txt", FACTURAS)
…   (lo mismo con los otros cinco)
[18]  informe(3 facturas · total $302.500)
listo 8 archivos en 3 carpetas · tokens: 3.900 + 900
  5. Revisa el resultado: abre las tres carpetas e informe.md. ¿Acertó con «doc1.txt»? ¿Sumó bien? Si algo quedó mal, se ajusta el pedido, no se arregla a mano.
  6. Vuelve a revolverlo y repite: pídele a Claude Code «devuelve todo a revuelto/» y corre otra vez. Un agente sirve si funciona siempre, no una vez.
Lo hace el agenteLeer, decidir y mover, archivo por archivo, sin cansarse.
Lo haces túLas carpetas, las reglas, los límites y revisar que el resultado esté bien.

05

Le sumamos MCP al agente

El agente ya ordena una carpeta de prueba. Con MCP, la misma IA llega a donde están tus archivos de verdad.

El agenteClaude Code con tus reglas
MCPun enchufe estándar, como el USB-C
Tu carpeta El correo Calendario Drive

Con la API, tu programa llama a la IA. Con MCP, la IA usa conexiones que otros ya construyeron: no programas la conexión.

El ejemplo: la misma carpeta, ahora por MCP

  1. Conecta el MCP en la terminal de VS Code:
    En la terminal
    claude mcp add carpeta -- npx -y @modelcontextprotocol/server-filesystem C:\agente\revuelto
  2. Revisa que quedó: en Claude Code, escribe /mcp.
  3. Pídele lo mismo, ahora por MCP:
    Pedido para copiar en Claude Code
    Devuelve todos los archivos a revuelto/.
Luego, sin usar agente.py, usa el MCP «carpeta» para ordenarlos tú:
FACTURAS, ESTUDIO o PERSONAL, y un informe.md con el total de las facturas.
No borres nada. Dime qué hiciste en cada paso.

Con Drive

Con su MCP, la IA ordena tus documentos de Drive con las mismas reglas.

Con el correo

Las facturas que llegan por correo, al informe del mes.

Con cuidado

Solo conectores de confianza: el agente actúa con tus permisos.
Muestra el /mcp y corre el pedido. Cierra con la idea: el trabajo es el mismo; con agente.py lo programaste tú, con MCP la IA usa una conexión que ya existe.
