01

El editor: VS Code

Es donde vamos a trabajar las tres sesiones.

Descárgalo de code.visualstudio.com e instálalo con las opciones que trae. Si ya lo tienes, actualízalo: Ayuda → Buscar actualizaciones.

En Windows, durante la instalación marca «Agregar a PATH» y «Abrir con Code» en el menú contextual. O instálalo desde la terminal:

PowerShell
winget install -e --id Microsoft.VisualStudioCode

En macOS, arrastra la app a Aplicaciones. Después ábrela, presiona ⌘⇧P, escribe «shell command» y elige «Install 'code' command in PATH».

En Linux, descarga el .deb (Ubuntu, Debian) o el .rpm (Fedora) e instálalo con doble clic, o:

Terminal
sudo snap install code --classic

Para comprobarlo, abre una terminal nueva y escribe:

code --version
02

Lo de base: Git, Node.js y Python

Los agentes de terminal corren sobre Node.js; el código de la sesión 03 lo escribimos en Python.

Instala las tres. Si alguna ya la tienes, revisa que la versión sea igual o más nueva que la indicada.

PowerShell · las tres de una vez
winget install -e --id Git.Git
winget install -e --id OpenJS.NodeJS.LTS
winget install -e --id Python.Python.3.13

Sin winget, descárgalas de git-scm.com, nodejs.org (la versión LTS) y python.org. En el instalador de Python marca «Add python.exe to PATH»: es la casilla que más problemas evita.

Terminal · Git viene con las herramientas de Apple
xcode-select --install

Node.js (la versión LTS) y Python, desde sus instaladores: nodejs.org y python.org. Si usas Homebrew:

Terminal · con Homebrew
brew install node python
Terminal · Ubuntu / Debian
sudo apt update
sudo apt install -y git python3 python3-venv python3-pip

Node.js: el de apt suele venir viejo. Instala la versión LTS desde nodejs.org (sección «Package manager»).

Dile a Git quién eres (una sola vez, con tu nombre y tu correo):

git config --global user.name "Tu Nombre"
git config --global user.email "tu@correo.com"

Cierra la terminal, abre una nueva y comprueba:

git --version      # 2.40 o más
node -v            # v20 o más
npm -v
py --version       # 3.11 o más
git --version      # 2.40 o más
node -v            # v20 o más
npm -v
python3 --version  # 3.11 o más

Opcionales

Si PowerShell dice que «la ejecución de scripts está deshabilitada», ejecuta esto una vez y vuelve a intentarlo:

Si npm pide permisos («EACCES»), no uses sudo: es mejor instalar Node.js con el instalador oficial o con nvm, que dejan los paquetes globales en tu usuario.

05

Una llave de API sesión 03

Para que tu propio código hable con el modelo.

Una llave de API es una contraseña que le da a tu programa acceso al modelo. Con una basta; la de Gemini tiene nivel gratuito y es la que usaremos en la prueba.

Gemini gratis para empezar

En aistudio.google.com/apikey → Create API key. Solo con tu cuenta de Google.

Anthropic (Claude) con saldo

En console.anthropic.com → API Keys. Necesita una recarga pequeña (desde 5 USD).

OpenAI (GPT) con saldo

En platform.openai.com/api-keys. También con una recarga pequeña.

Cuida tu llave como una contraseña. No la pegues en el chat de la clase, no la subas a GitHub y no la mandes por WhatsApp. Si se te escapa, bórrala en la misma página y crea otra: tarda un minuto. En las de pago, pon un límite de gasto mensual.

Guárdala por ahora en un lugar seguro (tu gestor de contraseñas, por ejemplo). En el siguiente paso la ponemos donde va.

06

La prueba final

Una carpeta de trabajo y un programa de cinco líneas que le habla al modelo. Si esto funciona, estás listo.

  1. Crea la carpeta del bootcamp y ábrela en VS Code:
PowerShell
mkdir $HOME\bootcamp-agentic
cd $HOME\bootcamp-agentic
code .
Terminal
mkdir -p ~/bootcamp-agentic
cd ~/bootcamp-agentic
code .
  1. En VS Code abre la terminal integrada (Terminal → Nueva terminal) y crea un entorno de Python con sus librerías:
Terminal de VS Code
py -m venv .venv
.venv\Scripts\activate
pip install google-genai python-dotenv openai anthropic
Terminal de VS Code
python3 -m venv .venv
source .venv/bin/activate
pip install google-genai python-dotenv openai anthropic

Al activarlo, la línea de la terminal empieza con (.venv). Así sabes que estás dentro.

  1. Crea un archivo llamado .env (con el punto al principio) y pega tu llave así, sin comillas ni espacios:
.env
GEMINI_API_KEY=pega-aqui-tu-llave
  1. Y uno llamado .gitignore, para que la llave nunca termine en GitHub:
.gitignore
.env
.venv/
  1. Crea prueba.py con esto:
prueba.py
from dotenv import load_dotenv
from google import genai

load_dotenv()                      # lee la llave del archivo .env
cliente = genai.Client()

respuesta = cliente.models.generate_content(
    model="gemini-flash-latest",
    contents="Saluda al Bootcamp AGENTIC en una frase corta y entusiasta.",
)
print(respuesta.text)
  1. Ejecútalo:
py prueba.py
python3 prueba.py

Si ves una frase de saludo, lo lograste. Tu editor, tu terminal, Python y tu llave de API funcionan juntos.

¿Tienes llave de Anthropic? Prueba también con Claude

Agrega ANTHROPIC_API_KEY=… en el .env y crea prueba_claude.py:

from dotenv import load_dotenv
import anthropic

load_dotenv()
cliente = anthropic.Anthropic()

mensaje = cliente.messages.create(
    model="claude-haiku-5-5",
    max_tokens=100,
    messages=[{"role": "user", "content": "Saluda al Bootcamp AGENTIC en una frase."}],
)
print(mensaje.content[0].text)

Si algo no funcionó

Lo que más suele pasar, y cómo se arregla.

«no se reconoce como un comando» / «command not found»

La terminal se abrió antes de instalar. Ciérrala del todo —también la de VS Code— y abre una nueva. Si sigue igual, reinicia el computador. En Windows, con Python, reinstálalo marcando «Add python.exe to PATH».

En Windows, python abre la Microsoft Store

Usa py en lugar de python, como en esta guía. O desactiva el atajo en Configuración → Aplicaciones → Alias de ejecución de aplicaciones.

.venv\Scripts\activate da error de permisos

Es la política de PowerShell. Ejecuta Set-ExecutionPolicy -Scope CurrentUser RemoteSigned y vuelve a activarlo.

La prueba dice «API key not valid» o «401»

Revisa el .env: el nombre exacto (GEMINI_API_KEY), sin espacios alrededor del igual, sin comillas, y que el archivo se llame .env y no .env.txt. En Windows, activa «Extensiones de nombre de archivo» en el Explorador para verlo.

«429», «quota» o «rate limit»

Se agotó el cupo del momento. Espera un minuto y vuelve a intentar. Con el nivel gratuito de Gemini pasa si se hacen muchas pruebas seguidas.

El computador es de la empresa y no me deja instalar

Pide a tu área de sistemas permisos de instalación para VS Code, Git, Node.js y Python, o usa un computador personal. Las redes corporativas a veces bloquean npm o las APIs: prueba desde otra red antes del bootcamp.

Nada de lo anterior

Anota el mensaje de error exacto —una captura sirve— y tráelo a la primera sesión, o escríbele al equipo del bootcamp antes. Con el mensaje, casi siempre es un minuto.
